## Summary

An experimental reward-scaling mod for the Steam version of World War Z:
Aftermath. Sets selected reward calculations to a factor of 90 and includes
install, verification, and restore commands.

## Description

Zeke Surge changes selected PvE reward, challenge currency, and weapon reward
calculations. The effect depends on the reward path; this is not a guarantee
that every reward or XP source will increase by exactly 90 times.

This package targets Steam build 23892411. Its installer checks the build and
the original game bundle before applying changes. Compatibility with other
builds or storefronts has not been established.

Extract the complete archive before using Install_Online_Mod.cmd.
Verify_Mod.cmd checks the installed bundle. Uninstall_Mod.cmd restores it
using the original-data backup created during installation; retain that backup.
These restore operations concern the game bundle, not progression or save data.

The existing package is labelled friends-only, but this label does not establish
permission to use it online. It does not block network access, and online safety
or current in-game compatibility has not been verified for this submission.
